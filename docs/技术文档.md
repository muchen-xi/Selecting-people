# 抽人 —— 技术文档

> 课堂随机点名工具 · Python + pygame
> 本文档面向二次开发与维护，介绍架构设计、数据格式与关键实现细节。

---

## 1. 架构总览

```
main.py ── 单文件程序
 ├── 全局常量：BASE_DIR / 资源路径 / 时区
 ├── class file：名单与轮次数据管理
 ├── 界面辅助：center_text / draw_panel / draw_log_screen
 ├── show_missing_files：资源缺失兜底提示
 └── __main__ 主循环：
     ├── 日志查看状态（show_log）
     ├── 事件处理（数字/空格/M/R/Y/L/ESC）
     └── 两个渲染分支（preparing / ready）
```

单文件设计（`main.py`），无外部依赖模块，仅依赖 `pygame`。所有资源与数据文件均基于 **exe/脚本所在目录** 定位（`BASE_DIR`），不依赖进程当前工作目录。

### 1.1 资源路径锚定

```python
if getattr(sys, "frozen", False):
    BASE_DIR = os.path.dirname(sys.executable)   # 打包后：exe 所在目录
else:
    BASE_DIR = os.path.dirname(os.path.abspath(__file__))  # 开发时：脚本目录
```

打包（PyInstaller onedir）后，`name_list.txt`、`log.txt`、`picked.txt` 与资源文件全部读写于 exe 同目录，**从任何工作目录启动均正常**。

### 1.2 窗口定位

```python
try:
    _dw, _dh = pygame.display.get_desktop_sizes()[0]
except Exception:
    _dw, _dh = 1920, 1080
os.environ["SDL_VIDEO_WINDOW_POS"] = "%d,%d" % (max(0, (_dw - 1800) // 2), max(0, (_dh - 1000) // 2))
```

在 `set_mode` 前通过 SDL 环境变量将窗口固定到**主显示器中央**，解决多显示器/位置记忆导致的窗口跑到屏幕外的问题。

## 2. 状态机

```
                    数字 1-9 + 回车（1~6）
   ┌──────────┐ ──────────────────────────► ┌──────────┐
   │ preparing│                            │  ready    │
   │ 准备界面  │ ◄────────────────────────── │ 抽人界面  │
   └──────────┘        空格(condition翻转)   └──────────┘
```

- **preparing**：等待输入人数；`M` 切换模式、`R`+`Y` 重置轮次在此状态处理
- **ready**：进入后 `condition == 1` 时每帧重新随机抽选（**滚动动画效果**）；按空格 `condition` 翻转为 `-1`，名字定格、写入日志/移除名单；再按空格回到 `1` 继续抽下一批

> 空格只在 `ready` 状态生效，准备界面误触无副作用（历史版本中准备界面按空格会翻转状态导致崩溃，已修复）。

## 3. 数据结构

### 3.1 `class file`

| 属性 | 说明 |
|---|---|
| `clean_lines` | 随机模式剩余名单（抽中即移除） |
| `all_names` | 完整名单（轮次模式抽取来源） |
| `numbers` / `number` | 输入的数字列表 / 拼接字符串 |
| `picked` | 轮次模式本轮已抽名单（内存 + `picked.txt` 持久化） |

| 方法 | 说明 |
|---|---|
| `open_file()` | 读取 `name_list.txt`，过滤空行，同时填充 `all_names` |
| `addtion()` | 数字列表拼接为字符串（空则为 "0"） |
| `load_picked()` / `save_picked()` | 读取/保存 `picked.txt` |
| `reset_round()` | 清空本轮记录（开启新一轮） |
| `round_left()` | 轮次模式剩余可抽人数 |

### 3.2 数据文件格式

**name_list.txt**（UTF-8，每行一个名字）：

```
张三
李四
王五
```

- 空行自动忽略（`if line.strip()`）
- 行首尾空白与双引号会被去除（`strip().strip('"')`）

**log.txt**（追加写入，北京时间 UTC+8）：

```
北京时间2026-08-30 09:00:00.123456+08:00抽到张三
```

- 时区：`timezone(timedelta(hours=8))`，不依赖系统时区设置
- 程序内按 `L` 可查看，显示时自动美化（时间/姓名间补空格）

**picked.txt**（轮次模式，每行一个已抽名字）：

```
张三
李四
```

- 程序自动创建；**删除该文件 = 开启新一轮**
- 跨程序重启保持，实现"长期周期内每人只抽一次"

## 4. 关键实现

### 4.1 两种抽人模式

```python
if mode == "round":
    # 轮次模式：全名单 - 本轮已抽
    available_names = [n for n in text_file.all_names if n not in text_file.picked]
    target_count = min(int(text_file.number), len(available_names))
else:
    # 随机模式：剩余名单，不足时重读
    if len(text_file.clean_lines) < int(text_file.number):
        text_file.open_file()
    available_names = text_file.clean_lines.copy()
    target_count = min(int(text_file.number), len(available_names))
```

- `random.sample(available, min(target, len(available)))` 保证不重复且名单不足时不崩溃
- 轮次模式剩余不足时，回车会提示"本轮剩余 X 人，不够抽 N 个，按R重置"，**不自动重置**，由老师决定（R + Y 确认，防误触）
- 确定人选后（`condition == -1`）写入日志；轮次模式同时 `save_picked()` 持久化

### 4.2 小键盘输入（NumLock 无关）

```python
elif 89 <= event.scancode <= 97:
    # SDL 标准 scancode：小键盘 1-9 物理键位
    text_file.numbers.append(event.scancode - 88)
```

pygame 的 `keycode`（如 `K_KP1`）会随 **NumLock 状态**变化——NumLock 关闭时小键盘数字变成方向键/END 等 keycode，导致按数字无反应。改用 **scancode（物理键位，SDL 标准 89~97 为 KP_1~KP_9）** 后，NumLock 开/关均可输入。

### 4.3 音乐切换（静音替代暂停）

```python
music_on = not music_on
pygame.mixer.music.set_volume(0.2 if music_on else 0.0)
```

历史版本使用 `pause()/unpause()`，在部分真实声卡上多次切换后 **SDL_mixer 死锁**（主循环卡死、界面无响应）。改为音量静音方案后，音乐状态机不再参与，**无死锁风险**，听感一致。

### 4.4 界面排版

- 全部文字水平居中（`center_text` 按字体宽度计算 x）
- 内容收纳于半透明白色圆角面板（`draw_panel`，SRCALPHA + `border_radius`）
- 配色：紫标题 `(96,82,168)` / 深紫蓝正文 `(70,62,110)` / 亮紫强调 `(108,92,231)` / 橙提示 `(224,118,60)` / 灰辅助 `(110,105,130)`

### 4.5 日志查看窗口

- 按 `L` 进入独立显示分支（`show_log`），与主循环互斥
- 日志行**倒序**（最新在上），支持 `↑↓` / `PageUp` `PageDn` / 滚轮滚动
- 只渲染可见行（`start..end` 切片），日志量大时也流畅
- `ESC` 或 `L` 关闭；打开时重新读取 `log.txt`，抽完立即能看到结果

### 4.6 资源缺失兜底

启动时检查 `name_list.txt` / `background.png` / `STKAITI.TTF` / `music.mp3` 是否存在，缺失时用系统字体（微软雅黑）弹出中文提示窗口，而不是无声闪退。

## 5. 打包与发布

### 5.1 exe（PyInstaller）

```bash
pyinstaller --noconfirm --clean --onedir --windowed --name 点我 --icon app.ico main.py
```

- `--onedir`：启动快、杀软误报少（`_internal` 存放运行库）
- `--windowed`：无控制台窗口
- 产物 `dist/点我/`，需将资源文件（字体/背景/音乐/名单）复制到同目录

### 5.2 安装包（Inno Setup）

`installer/抽人_安装包.iss`：

- 中文向导（需将 `ChineseSimplified.isl` 放入 Inno Setup 的 Languages 目录）
- `PrivilegesRequired=lowest`：无需管理员权限，装到 `%LOCALAPPDATA%\Programs\抽人`
- 开始菜单 + 可选桌面快捷方式，自带卸载程序
- 分发内容**不含**源码、旧日志与真实名单（`name_list.txt` 为示例）

## 6. 常见问题

**Q：目标电脑没装 Python 能跑吗？**
A：能。PyInstaller 已把 Python 解释器（`python39.dll`）与依赖全部打进 `_internal`，exe 完全自包含。

**Q：为什么窗口有时会出现在屏幕外/副屏？**
A：历史版本 SDL 默认位置受记忆/多显示器影响。现版本启动时通过 `SDL_VIDEO_WINDOW_POS` 固定主屏居中，已解决。

**Q：抽到的人怎么恢复？**
A：随机模式抽空名单后自动重置；轮次模式按 `R` 再按 `Y` 手动开新一轮（或直接删除 `picked.txt`）。

**Q：日志时间为什么是北京时间？**
A：`log.txt` 固定使用 UTC+8（`timezone(timedelta(hours=8))`），与系统时区无关。

**Q：名单文件有 BOM 或空行会怎样？**
A：空行自动忽略；行首尾空白和引号自动去除。若文件以 UTF-8 BOM 开头，首行名字会带上 `\ufeff`，建议用记事本另存为"UTF-8 无 BOM"。
